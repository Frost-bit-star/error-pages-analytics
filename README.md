# error-pages-analytics

## Analytics

ErrorLab collects anonymous usage data to improve template rankings and discoverability.

We collect only:
- Template name
- Framework type
- Error type (404 / 500)
- CLI source

We do NOT collect:
- IP addresses
- Personal or device data
- User identity

## Stats

Live template usage stats are stored in this repository:

https://github.com/ui-errors/error-pages-templates

File:
`stats.json`

It tracks:
- Total installs per template
- Framework usage
- Error type distribution
